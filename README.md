# Sanjay S - Developer Portfolio

Welcome to the repository for my personal developer portfolio! This project is a modern, responsive website designed to showcase my engineering skills, projects, certifications, and professional resume.

## 🌐 Live Demo

**[View the Live Portfolio Here](https://sanjay-github-portfolio.vercel.app/)**

## ✨ Features

- **Modern & Responsive UI:** Designed with a sleek dark theme, glassmorphism effects, and smooth micro-animations.
- **Dynamic Content Rendering:** Features an interactive project filtering system and modal details for deeper insights into each project.
- **Print-Ready Resume:** Includes a dedicated HTML resume (`Sanjay_Resume.html`) styled for A4 printing and direct PDF downloads.
- **Interactive Contact Form:** A clean UI contact form with mock submission feedback (ready to be integrated with a backend email service).
- **SEO Optimized:** Meta tags and semantic HTML structure implemented for better search engine visibility.

## 🛠️ Technology Stack

This portfolio is built using core web technologies, ensuring lightweight performance and high customizability:
- **HTML5:** Semantic structure and content organization.
- **CSS3 (Vanilla):** Custom styling using CSS variables, Flexbox, Grid, and keyframe animations without heavy frameworks.
- **JavaScript (Vanilla):** DOM manipulation, tab navigation, portfolio filtering, and modal interactions.

## 🚀 Key Projects Highlighted

- **AI Internship Finder:** An intelligent web tool utilizing resume parsing and skill-matching algorithms.
- **Identity Verification System Using Blockchain:** A decentralized application focusing on secure, tamper-proof digital records.
